# Instagram Auth — бэкенд + база данных

## Что это
Node.js сервер (Express) со страницей входа/регистрации в стиле Instagram.
Все введённые данные сохраняются в настоящую базу данных SQLite (файл `users.db`),
которую можно посмотреть прямо в браузере.

## Как запустить

1. Установи [Node.js](https://nodejs.org) (если ещё не установлен).
2. Открой терминал в этой папке и выполни:
   ```
   npm install
   ```
3. Запусти сервер:
   ```
   npm start
   ```
4. Открой в браузере:
   - **Вход/регистрация:** http://localhost:3000/index.html
   - **Просмотр всех введённых данных:** http://localhost:3000/admin.html

## Как это работает
- При регистрации данные (email, имя, юзернейм, пароль) отправляются на сервер и сохраняются в SQLite базу `users.db`.
- При входе сервер проверяет логин/пароль в этой же базе.
- На странице `/admin.html` можно увидеть всех зарегистрированных пользователей и удалить любого из них.
- База данных — это обычный файл `users.db`, который появится в папке проекта после первого запуска. Его также можно открыть любой программой для просмотра SQLite (например, [DB Browser for SQLite](https://sqlitebrowser.org/)).

## Важно
Это учебный/демо-проект. Пароли хранятся в открытом виде (без хеширования) —
для реального продакшена так делать нельзя, нужно использовать bcrypt и HTTPS.
